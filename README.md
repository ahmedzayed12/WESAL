# وصال — الإصدار 1.0

منصة تواصل اجتماعي عربية: منشورات وصور وفيديو وريلز وقصص، صداقات ومتابعة، تعليقات وتفاعلات، إشعارات، بلاغات وإشراف.
هذا الإصدار إعادة بناء كاملة للنسخة Alpha 0.3 لتكون **جاهزة للنشر العام وقابلة للتوسع الأفقي**.

## ما الذي تغيّر عن Alpha 0.3

| المجال | Alpha 0.3 | الإصدار 1.0 |
|---|---|---|
| التخزين | ملف `data.json` يُعاد كتابته كاملًا مع كل طلب | PostgreSQL مع فهارس ومعاملات (transactions) |
| المصادقة | ترويسة `X-User-Id` (أي شخص ينتحل أي حساب) | تسجيل وكلمات مرور (scrypt) وجلسات بكعكة httpOnly وتسجيل خروج من كل الأجهزة |
| الأمان | لا يوجد | حماية CSRF، ترويسات CSP/HSTS، تحديد معدل الطلبات، قفل الحساب بعد محاولات فاشلة |
| رفع الوسائط | base64 داخل JSON (حجم +33% وكل الملف في الذاكرة) | رفع مباشر إلى S3 بروابط موقّعة، أو تدفق خام للتخزين المحلي، مع فحص التوقيع الحقيقي للملف |
| عرض الوسائط | فحص كل المنشورات في الذاكرة لكل صورة | استعلام واحد مفهرس + رابط موقّع قصير العمر |
| القوائم | كل المنشورات دفعة واحدة | ترقيم بالمؤشر (keyset) ثابت الأداء مع أي حجم بيانات |
| التوسع | عملية واحدة فقط (الحالة في الذاكرة) | خوادم عديمة الحالة خلف موازن أحمال + Redis مشترك |
| التشغيل | يدوي | Docker Compose مع HTTPS تلقائي ونسخ احتياطي يومي وفحوص صحة وإيقاف رشيق |
| ميزات جديدة | — | استكشاف، بحث، ملف شخصي، طلبات متابعة للحسابات الخاصة، إلغاء صداقة/حظر، إشعارات، بلاغات ولوحة إشراف، حذف الحساب، تعديل المنشور |

## البنية

```
المتصفح ──HTTPS──► Caddy (موازن أحمال + شهادات تلقائية)
                     ├──► app × N   (Node.js / Fastify — عديمة الحالة)
                     │      ├── PostgreSQL  (البيانات)
                     │      ├── Redis       (الجلسات المؤقتة + تحديد المعدل)
                     │      └── S3 / MinIO  (الوسائط)
                     └──► MinIO (روابط الرفع/التنزيل الموقّعة)
worker × 1  (تنظيف القصص المنتهية والوسائط اليتيمة والجلسات)
backup      (pg_dump يومي)
```

```
src/
  server.js        نقطة التشغيل + الإيقاف الرشيق
  app.js           إعداد Fastify: الأمان، المصادقة، تحديد المعدل، فحوص الصحة
  routes/          auth · users · posts · media · social (قصص، إشعارات، بلاغات)
  worker.js        عامل الخلفية
  migrate.js       ترحيل قاعدة البيانات (آمن مع عدة نسخ)
migrations/        مخطط SQL
public/            الواجهة العربية (RTL، بدون مكتبات خارجية)
tests/             اختبارات تكامل على Postgres وRedis حقيقيين
scripts/           make-admin.js · seed-benchmark.js
```

## التشغيل المحلي للتطوير

المتطلبات: Node.js 20+، PostgreSQL 14+، Redis 6+.

```bash
npm install
createdb wesal
npm run migrate
npm start
```

افتح http://localhost:3000 وأنشئ حسابًا. في التطوير تُحفظ الوسائط في مجلد `uploads/`.

متغيرات البيئة المهمة (القيم الافتراضية مناسبة للتطوير): `DATABASE_URL`، `REDIS_URL`، `APP_ORIGIN`، `STORAGE_DRIVER` (`local` أو `s3`)، `S3_*`. انظر `src/config.js`.

## الاختبارات

```bash
createdb wesal_test
npm test
```

17 اختبار تكامل تغطي: المصادقة، CSRF، الخصوصية والجمهور، الصداقة والمتابعة والحظر، الترقيم، التفاعلات، التعليقات، الرفع وفحص التوقيع وصلاحيات الوسائط، الريلز، انتهاء القصص وتنظيفها، البلاغات وإيقاف الحسابات، حذف الحساب، وتحديد المعدل.
تعمل الاختبارات تلقائيًا في GitHub Actions مع كل دفع (`.github/workflows/ci.yml`).

```bash

```
